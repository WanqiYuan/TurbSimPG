# TurbSimPG

Official implementation of the paper **Volumetric Simulation and Rendering of Heat-induced Optical Turbulence at Interactive Rates**.

## Requirements

- Unity `6000.3.9f1`

## Scene settings

After opening a scene, its main settings can be adjusted from the **Hierarchy** panel on the left side of the Unity Editor:

- Select **Global Volume** to modify the raymarching and rendering settings.
- Select **Simulation** to modify the fluid simulation settings.

## Getting started

1. Download or clone this repository.
2. Download the required `Prefab` folder from Google Drive: [Download Prefabs](GOOGLE_DRIVE_LINK_HERE).
3. Place the downloaded `Prefab` folder directly inside the project's `Assets` directory. The resulting path should be `Assets/Prefab`.
4. Open the project with Unity `6000.3.9f1`.
5. In the Unity Project window, open `Assets/Scenes` and select a scene.
6. Click the **Play** button in the Unity Editor to run the simulation.
